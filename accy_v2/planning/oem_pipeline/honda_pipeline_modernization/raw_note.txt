Types of records in the Honda files. These apply to both sheets (EN and FR) of course with their appropriate language specifics as defined in the config files. 

- Vehicle signature records (meta): these are records that identify which vehicle model name, year, and it also has a manufacture signature data. These are situated a the top of the file, before the marker of the firs data record section as defined in the config. these are to be extracted and stored to identify which batch file is being processed.
-  Price publication date: these are records that specify the date at which these prices will be in effect. they are two rows situated are usually situated at the end of the file, after the last section of the file. The first one contains string EN: "Publication Date", FR: "Date de publication", and the following one contains a date format value, usually on the same column as where description data is in on the file.
