THE PROBLEM
================================================================================

88 model lookups are failing across Hyundai and Genesis vehicles. These failures
follow a CLEAR PATTERN - the same trim keywords fail consistently across all
years (2024, 2025, 2026).

Examples of failing trims:
  - Elantra: Ult, N-Line
  - Santa Fe: Lux, XRT, Pref HEV, Ult Calli, HEV NHL Ed (18 failures)
  - Tucson: N-Line, PHEV, Pref*, Trend*, XRT (15 failures)
  - Kona: N-Line, Trend, Sport (10 failures)
  - Genesis: G70 2.0T Advanced, G90 3.5T e-SC (8 failures)

IMPACT:
  - ~88 parts are excluded from output because their trim combos don't get
    matched to model numbers
  - This is NOT random - same issue repeated across multiple models and years

================================================================================
ROOT CAUSE (NOT YET FULLY CONFIRMED - NEEDS DEBUGGING)
================================================================================

The translator HAS the mappings (e.g., "hev" → "hybrid"), the database HAS the
records (e.g., "Santa Fe 1.6T Preferred Hybrid AWD 7-Pass"), but the search is
still returning None.

MOST LIKELY CAUSES (in order of likelihood):

1. ⚠️  SCORING TOO STRICT (60% likelihood)
   - Multi-keyword searches (4+ keywords) fail the adaptive score threshold
   - E.g., "Santa Fe Pref HEV" = MODEL(10) + TRIM(6) + DRIVETRAIN(?) = maybe 12
   - But threshold for 4+ candidates is 14
   - Solution: Check scoring weights, adjust if needed

2. ⚠️  KEYWORD CLASSIFICATION ISSUE (20% likelihood)
   - Translated keywords not being recognized by classifier
   - E.g., "hybrid" translated but not classified as DRIVETRAIN
   - Solution: Verify classifier config

3. ⚠️  INPUT PREPROCESSING (10% likelihood)
   - Keywords like "Pref*" and "Trend*" have trailing asterisks
   - These don't match translator entries (which only have "pref", "trend")
   - Solution: Strip asterisks before processing

4. ✅ DATABASE COVERAGE (8% likelihood)
   - Unlikely - database analysis shows most trims ARE present
   - But could be missing specific year+trim combinations

5. ❌ TRANSLATOR MISSING ENTRIES (2% likelihood)
   - Only affects "ICE", "EDT.HEV" (2-3 failures)
   - "HEV", "PHEV", "EV" ARE in translator

================================================================================
WHY IT'S NOT RANDOM - PROOF OF PATTERN
================================================================================

Same failure pattern across years suggests ROOT CAUSE is NOT input data or
database gaps, but rather a systematic issue in the pipeline.

EVIDENCE:
  ✅ "Lux" fails in Santa Fe 2024, 2025, 2026 (same way each time)
  ✅ "N-Line" fails in Elantra 2025, 2026 (consistent)
  ✅ "Tucson Trend*" fails in 2025, 2026 (identical error)
  ✅ "G70 2.0T Advanced" fails in 2024, 2025 (both years)

If it were database gaps, different years would have different patterns.
If it were random, we'd see different error messages.
But they're IDENTICAL across years → systematic pipeline issue.
