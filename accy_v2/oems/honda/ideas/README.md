## Process

1. **Discovery**: An issue or improvement idea emerges during development
2. **Documentation**: Strategy document created here with problem, solution, and roadmap
3. **Approval**: User confirms approach before implementation
4. **Implementation**: Execute Phase 1, then Phase 2 if needed
5. **Tracking**: Move to completed when deployed and tested
6. **Learning**: Reference for future OEMs or similar issues

---

## How to Add a New Idea

1. Create a new markdown file with clear, descriptive name (UPPER_CASE_SNAKE.md)
2. Use the template structure:
   - Problem Statement
   - Strategic Solution
   - Implementation Roadmap
   - Risk Assessment
   - Expected Outcomes
3. Add entry to this README
4. Link from relevant project documentation
5. Update project status when implemented
