HOW TO RUN THE PIPELINE NOW:
============================

1. Open the notebook:
   scripts/honda_processor.ipynb

2. Run all cells:
   Kernel → Restart & Run All (or Ctrl+Shift+Enter)

3. Watch the console output for logging messages like:
   [MATCHER DEBUG] Starting model attachment for 217 rows
   [MODEL ATTACHMENT] Using matcher (db has 217 records)
   [MATCHER DEBUG] Completed: 217/217 rows with model numbers
   [EXCEL EXPORT] Column 'Model': 217 non-null values

4. Check the output file:
   ready_to_upload/2026/Honda/Honda_Accessories-Upload_file-<timestamp>.xlsx

   Look for Column "Model" to have:
   - ✓ Values like: YF9H5TK, FE2F5SJ, RS4H5RJS (CORRECT - Honda model codes)
   - ✗ NOT: LX 2WD, EX, TOURING (WRONG - trim names)

TROUBLESHOOTING:
================

Q: I don't see the logging output
A: Make sure you ran "Kernel → Restart & Run All" not just individual cells

Q: I see "[MODEL ATTACHMENT] Using stub (db is None)"
A: Database wasn't loaded - check that honda_models.csv exists in models_catalogue/

Q: I see "0/217 rows with model numbers"
A: Matcher returned no matches - check vehicle data format in extracted results

Q: Output file still has trim names instead of model codes
A: Model numbers weren't attached to the dataframe - check logs for which step failed

Q: No output file was created
A: Check that excel export completed - look for errors in console
